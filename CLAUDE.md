# Protección obligatoria del proyecto NEXO

Antes de analizar o modificar este proyecto, lee y aplica íntegramente `AGENTS.md`.

No borres, renombres, muevas ni sustituyas archivos sin comprobar antes sus referencias y ejecutar `npm run audit`. Conserva siempre una versión estable recuperable. Tras cualquier cambio ejecuta `npm test`; no prepares una entrega si la auditoría o las pruebas fallan.

`proteccion-archivos.json` es el inventario de seguridad. No debe modificarse para ocultar una pérdida. Solo puede actualizarse cuando la usuaria haya pedido expresamente añadir, sustituir, mover o retirar un recurso y la modificación se haya verificado.
